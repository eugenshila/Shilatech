# Approved Shilatech Visual Assets

The approved direction is a premium black-and-gold automotive theme with Jeep Wrangler / Grand Cherokee imagery.

For the final production artwork, place the approved high-resolution files in `public/` using these names:

- `shilatech-logo-premium.png` — final photographic/illustrated logo with Jeep.
- `shilatech-jeep-hero.jpg` — wide Jeep Wrangler or Grand Cherokee hero photograph.

The first redesign pass currently uses optimized SVG artwork so the branch remains self-contained and deployable without broken image links. Once the final image assets are committed, the Header/Hero components can switch to them without changing the page structure.
