# Preview Checklist

Before merging this redesign into `main`, verify:

1. Header is readable on desktop and mobile.
2. Homepage hero loads without missing assets.
3. Gold CTA buttons link to `/products`, `/request` and WhatsApp correctly.
4. All five vehicle-brand logos render correctly.
5. Featured product images and prices display correctly.
6. Product detail and WhatsApp buttons still work.
7. Footer links open expected pages.
8. `npm run build` succeeds.
9. Railway preview/deployment has no build or runtime errors.
10. Final photographic logo and Jeep hero assets are approved before production merge.
